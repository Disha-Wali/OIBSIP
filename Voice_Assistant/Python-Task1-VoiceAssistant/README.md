# Voice Assistant

## About the Project
A Python-based voice assistant that listens to user commands and performs tasks through speech recognition and voice responses.

## Features
- Recognizes voice commands.
- Responds using text-to-speech.
- Opens websites like Google, YouTube and Gmail.
- Provides date and time information.
- Performs Google searches.
- Supports continuous voice interaction.

## Technologies Used
- Python
- SpeechRecognition
- Pyttsx3
- Webbrowser

## How to Run
1. Install the required Python libraries.
2. Run `assistant.py`.
3. Allow microphone access.
4. Speak your commands to interact with the assistant.
