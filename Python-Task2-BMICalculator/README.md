# BMI Calculator

## About the Project
A Python-based BMI Calculator developed using Tkinter.

## Features
- Calculates Body Mass Index (BMI) using height and weight.
- Categorizes BMI results.
- Stores user records using SQLite.
- Displays BMI history through graphical charts.
- Provides a simple graphical user interface.

## Technologies Used
- Python
- Tkinter
- SQLite
- Matplotlib

## How to Run
1. Install Python.
2. Install Matplotlib using `pip install matplotlib`.
3. Run `bmi_calculator.py`.

This project was developed as part of the Oasis Infobyte Internship.
